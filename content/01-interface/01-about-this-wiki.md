# About this wiki

This is a small wiki. It lives in your terminal, it holds a crash course on
**Claude Code**, and it is the only copy of any of it — the agent you can
talk to reads these same pages. Anthropic publishes its own documentation,
and it is good: it tells you what every feature is. This is a different
thing. It covers the **Party Tricks** — the Boss's hard-learned lessons
about how Claude Code actually behaves, gathered from hours of practice,
tests, and commiseration on GitHub with people who hit the same problems.
The official docs are the reference; this is what someone found out by
doing it.

It is an early version, and it will grow.

## Where it is now

Version **0.1.0**. Enough to get you building things: **agents**,
**skills**, and **subagents**. Those three are where nearly all the value
is, and they are the ones worth learning first.

Everything before them — the terminal, the shell, where Claude Code keeps
its files — is here because you cannot build the three without it. It goes
quickly.

## What comes later

Claude Code has fancier machinery on top. It is left out on purpose: it is
worth having, and it makes little sense before the three above.

- **0.2.0 — connecting Claude Code.** Hooks, MCPs, plugins. Wiring it into
  the other things on your machine, and into the things that are not.
- **0.3.0 — automating Claude Code.** Crons, schedules and routines. Cloud
  computing. Machine learning. Work that happens whether or not you are
  sitting there.

Each one assumes the one before it. Read this version properly and the next
will feel like an extension rather than a new subject.
