# About this wiki

*v0.1.0*

This is a small wiki. It lives in your terminal, it holds a crash course on
**Claude Code**, and it is the only copy of any of it — the agent you can
talk to reads these same pages. Anthropic publishes its own documentation,
and it is good: it tells you what every feature is. This is a different
thing. It covers the **Party Tricks** — the Boss's hard-learned lessons
about how Claude Code actually behaves, gathered from hours of practice,
tests, and commiseration on GitHub with people who hit the same problems.
The official docs are the reference; this is what someone found out by
doing it.

It is an early version, and it will grow.

## What that means for how it reads

A Party Trick is a finding, not a feature. Nobody at Anthropic wrote down
that fifty agents piled into one folder makes every one of them worse, or
that a skill left to fire on its own frequently does not — those came out
of doing the work badly first. So this course argues rather than lists.
Where something has a limit, the limit is stated in the same breath as the
capability, because that is the shape the finding arrived in.

It also means the course is opinionated about order. Nothing here is
reference material you dip into; each part assumes the one before it, and
the parts that look least like Claude Code — the terminal, the shell, the
software already on your Mac — are the ones the later parts lean on
hardest.

What this version covers, what it holds back for a later one, and why the
order runs the way it does is the next article.
