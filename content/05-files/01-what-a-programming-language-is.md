# What a programming language is

*v0.2.0*

The shell drives a machine that already exists. Typing `rm` reaches
into a program someone else wrote and tells it to delete a file. A
**programming language** is what that program was written in — a way
of describing, in exact and exhaustive detail, a piece of software
that did not exist until you described it.

That is the distinction. The shell operates. A language builds what
gets operated on.

## What gets written in one

Every application on your Mac started as text in a programming
language, then went through a step that turned the text into
something the machine could run. Word, Acrobat, Claude Code itself —
each began as a file full of instructions in one language or another.

You do not need to read any of them to use this course, but the names
will come up, so here is what each is reached for:

- **Python.** Readable, forgiving, the language most often taught
  first. Data work, quick scripts, a large share of the tools a
  working agent reaches for on your behalf.
- **JavaScript.** The language of the web browser — almost everything
  on a page that moves or reacts, rather than merely sitting there,
  runs on it.
- **Go.** Compact and fast, reached for when a program has to run the
  same way on every machine with nothing extra installed. This
  reader's own binary is written in it.
- **Java, C++, C#, Rust.** Heavier languages, reached for when
  performance or scale matters more than how quickly the first
  version gets written.

None is more real than another, in the same way no shell command is
more real than another. Each is a different set of trade-offs for the
same underlying job: telling a machine, precisely, what to do.

## Where a script sits

A **script** is a small program, usually one file, usually written to
be run rather than sold — a few dozen lines that rename a folder of
files, or pull one figure out of a document, rather than a piece of
software with a name and an icon.

The boundary between a script and a programming language is blurrier
than it sounds, because a script is not a different language. It is
the same language, aimed at a smaller job. The Python that renames
your files and the Python that runs a data pipeline are the same
Python; what changed is the size of the thing being described, not
the tool describing it.

Claude Code writes scripts constantly, usually without you asking for
one by name. Ask it to rename forty files by date and it may hand you
the finished files, or it may hand you the few lines of code that did
it and offer to run them again next month. Either answer is the same
job, done in a language.
