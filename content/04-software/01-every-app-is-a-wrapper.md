# Every app is a wrapper

*v0.2.0*

Every app you have ever paid for is a pile of code in a wrapper.

Underneath Acrobat, underneath Word, underneath the Adobe subscription,
there is code that reads a PDF, code that compares two documents, code
that turns a scan into text. Very little of it is secret, and a
surprising amount of it is not even theirs.

## What is actually inside

Modern software is built out of small, self-contained pieces that each
do one job. A team building a document viewer does not write its own
code for reading a PDF from scratch — it takes a piece someone else
already wrote, tested and maintained, and puts a window around it. The
next team building a different document viewer often takes the same
piece.

That is true up and down the price range. A free tool and a
thousand-pound-a-year subscription can share the exact same code doing
the exact same job underneath, differing only in the window, the
support line, and what else is bundled alongside it.

## What you are buying

Most of the time, what money buys is the wrapper: an installer, a
menu bar, a licence key, a support line, a logo you recognise. Not the
capability itself — the capability was frequently available already,
written by someone else, for nothing.

That does not make the wrapper worthless. An installer that never asks
a question, a support line for when something breaks, a look and feel
matching every other program on the machine — these cost real effort to
build and are exactly what a paying customer is choosing. It does mean
the capability inside is not the scarce part. The scarce part is
someone packaging it for a person who does not want to know it is
there.

You are that person, most of the time, and there is nothing wrong with
it. Buying the wrapper is the right call for anything you use daily and
do not want to think about. The point is only that it is a choice, not
a law of nature — for the odd task the wrapper was never built for,
there is a second option, and until now you have not had a way to reach
it.

> **From the Boss.** He has never paid for a PDF tool since discovering
> that the merge, split and text-extraction functions of three separate
> pieces of paid software were the same handful of packages, wrapped
> three different ways.

That is the door this part opens. If the capability is not the scarce
part, it can be reached directly.

Press `n`.
