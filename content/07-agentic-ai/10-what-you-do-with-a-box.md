# What you do with a box

*v0.2.0*

A rented box arrives empty. Whatever the job needs — a model's weights,
a harness, the packages a project depends on — you install yourself,
the same way you would on a machine sitting on your desk. You run the
job, and when it is done you download the result and let the box go.

Nothing about the box is permanent, and nothing about it needs to be.
It exists for the length of the work and is billed for exactly that
long.

## Almost every box is Linux, and none of it has a desktop

Open one and there is no window, no dock, no icon to click. A terminal
prompt, and nothing else. That is not a stripped-down option among
several — it is close to the only shape a rented box comes in. Paying
for a desktop environment on a machine nobody is going to sit in front
of would be paying for nothing.

*What Linux is* covered the kernel underneath a desktop; a box is the
kernel with the desktop left off entirely, reached over the network
instead of a screen.

## What that used to cost you

A terminal-only Linux machine, until recently, meant you needed to
already know the shell — the commands, the paths, the syntax — before
you could get anything done on it at all. That was real friction, and
it kept a great many people away from boxes they could otherwise have
rented cheaply.

*You are the system* made the same point about a Linux machine on your
own desk: the cost was never secrecy, it was the weekend of forum posts
and configuration syntax standing between wanting something and having
it. The same removal applies here, and for the same reason. You do not
need to already know the shell commands a box wants. You say what the
job is, in plain English, from a session running on your own machine
and reaching into the box over the network, and the driving happens the
way it always has in this course — one agent, one loop, carrying out
what you asked for and reporting back.

The box supplies size. The harness supplies the driving. Neither one
was available to a working solicitor on her own before the other
existed alongside it.
