# What CLI, command line and prompt mean

*v0.2.0*

*What a terminal is* mentioned that *terminal*, *console*, *command line*
and *shell* get used almost interchangeably. That is true, and it is worth
thirty seconds of unpicking, because the words did not always mean the
same thing, and one of them — *CLI* — you will see written far more often
than you will hear it said.

This is short.

## Terminal and console

You already have *terminal*: the window itself, the software standing in
for a piece of hardware that used to sit on a desk. **Console** is the
older, narrower cousin. It meant the one terminal wired directly into a
machine, as opposed to one reached down a cable from somewhere else — the
operator's own desk, not a colleague's. Nobody preserves that distinction
now. If you see *console* in a menu or an error message, read it as
*terminal* and move on.

## The command line

The **command line** is not a window and not a program. It is the *style*
of interface: one where you operate a computer by typing instructions as
text, rather than by pointing at pictures and clicking. A terminal is
where the command line lives, the way a page is where a sentence lives —
but the sentence is the thing being described.

**CLI** is the short form, for *command-line interface*. It names the
same style, and it is what you will see written in software
documentation, package names and error messages — a tool describing
itself as "a CLI" is telling you it has no windows and no buttons, only
commands. It does not name a program, a window or a company. It names an
approach, and the opposite of it is a GUI.

## The prompt

The **prompt** is narrower still: the actual line where you type, the one
waiting for you with a cursor on it. Every command line has one. What it
looks like and what it tells you is its own subject, taken up in *The
CLI* — for the moment, only the word.

## Why the sloppiness is harmless

In practice these four words nest inside one another — terminal holds
command line, command line ends in a prompt, and console is an old name
for the whole stack — and on a modern machine there is only ever one
thing sitting in that stack at a time. That is why the loose usage costs
you nothing: say "terminal" when you mean "prompt" and everyone,
including Claude Code, understands you. The distinction in this article
is for reading unfamiliar sentences, not for writing your own more
carefully.

willing to draw it. Which ones, and what actually separates them, is the
