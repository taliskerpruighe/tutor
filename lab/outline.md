# Challenge 1 — outline

Structural outline only. No verbiage yet.

---

## 1. Opening — the situation

- A law firm practices naturalization.
- It builds a naturalization packet for each client.
- It has come to you with a challenge.

## 2. The challenge, stated once

- Build a plugin the firm can run on a Claude Code harness that produces an
  entire naturalization packet.

## 3. What the firm has given you

### 3.1 The worked examples

- A few examples, each one past client.
- Each example is a pair:
  - **Input** — what the client handed the firm.
  - **Output** — the packet the firm built from it.

### 3.2 What to notice about them

- The input looks different every time; it changes with the client.
- The output does not. It has a rhyme and a reason.
- That rhyme is the firm's house style — how it likes packets done.

### 3.3 The unfinished clients

- A few more input folders, with no output folder.
- These are packets still to be built — your proving ground.

## 4. What the firm is asking for — three parts

### 4.1 Where it runs

- It must run on the Claude Code harness.
- Running on your computer satisfies the challenge.
- The firm is all the more impressed if you can hand the plugin over and have
  it run on theirs.

### 4.2 What it does

- Take any client's input folder.
- Return an output folder as close as possible to the examples.

### 4.3 How simply it works

- One command in a terminal.
- One argument: the path to the client input folder.
- All the more impressive if the command is the word `naturalize`.

## 5. What you may build it out of

- A plugin folder, containing whatever mix you like of what the course has
  covered through Level 2 — agents, skills, workflows, commands.
- The composition is yours to choose.

## 6. Feel free to cheat (drafted as final H2)

- The firm would like the build to stay within Levels 1 and 2 of the course.
- Past that, work smart, not hard.
- Point an agent running in Claude Code at this challenge, the rest of the
  course, and the materials provided — it will take you a long way.
